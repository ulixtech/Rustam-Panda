Quick Setup

Up and Running in 30 Seconds

No complicated installation or node servers. Just load the clean Manifest V3 package directly into Chrome.

01

Clone or Download

Grab the latest version of the repository from GitHub.

git clone https://github.com/ulixtech/Rustam-Panda.git
02

Load in Chrome

Go to chrome://extensions/, enable Developer mode, and click Load unpacked to select the folder.

03

Open Meta Ads Library

Navigate to any advertiser on Facebook Ads Library and click the 🐼 Rustam Panda pill to extract everything.
